# Hospital Intelligence Dashboard | Excel

**Turning Hospital Data into Financial and Operational Insights**

An Excel-based hospital business intelligence dashboard designed to help hospital management monitor revenue, outstanding bills, collection performance, and patient waiting times.

**Author:** Dr. Bernard Muoneme  
**Role:** Data Analyst & Consultant  
**Tools:** Microsoft Excel, Data Analysis, Data Visualisation

## Project Overview

Hospital management requires timely, reliable information to understand financial performance and operational efficiency.

This project demonstrates how Microsoft Excel can be used to consolidate hospital performance indicators into a dashboard that supports management reporting, identifies areas requiring further investigation, and facilitates evidence-informed decisions.

## Business Problem

Hospital executives need visibility into questions such as:

- How much revenue has the hospital generated?
- How much money remains outstanding?
- What proportion of revenue has been collected?
- Where should management investigate potential collection gaps?
- How long do patients wait for services?
- Which financial and operational indicators require attention?

The dashboard brings key indicators together in a visual reporting interface.

## Key Performance Indicators

The demonstration scenario includes the following headline figures:

| KPI | Value |
|---|---:|
| Total revenue | ₦44,000,000 |
| Outstanding bills | ₦13,800,000 |
| Outstanding bills as a share of revenue | Approximately 31.4% |
| Collection rate | 69% |
| Average patient waiting time | 64 minutes |
